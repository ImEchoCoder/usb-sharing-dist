# USBFlow - Public Downloads

This repository contains only the public Windows installer for USBFlow.
The application source code is private and is not published here.

Download `USBFlow-0.3.1-setup.exe` from the latest release:
https://github.com/ImEchoCoder/usb-sharing-dist/releases/latest

SHA-256: E3148B009DD61ED662D16A7AFD715F0805421AC973F5BB1DF4F03F120ADA194C

Verify before running:

```
powershell -Command "Get-FileHash .\USBFlow-0.3.1-setup.exe -Algorithm SHA256"
```

The installer is unsigned; Windows SmartScreen may warn. Choose **More info → Run anyway** only after the hash matches.

Customer / Share is free. Technician / Connect requires a paid 1-year license.

Note: GitHub automatically shows "Source code (zip)" and "Source code (tar.gz)"
links on every release. Those archives are generated from this repository only;
they contain this README and no application source code.
